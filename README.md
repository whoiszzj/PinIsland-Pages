# PinIsland 支持网站

PinIsland 的隐私政策 / 帮助与支持 / 第三方许可页面(中英双语)。

- [中文入口](zh/) · [English](en/)

## 内容来源与更新

页面内容与 App 内“设置 → 关于与支持”的原生页面**同源**,生成于主项目
`PinIsland` 仓库的 `docs/`(生成器:`tools/generate_web_docs.py`)。

更新流程:在主项目改文案 → 运行 `python3 tools/generate_web_docs.py` →
把 `docs/` 中的 `index.html`、`assets/`、`en/`、`zh/` 同步到本仓库根目录并推送。
